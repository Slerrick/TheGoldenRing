# The Golden Ring

Образовательный VR-тур на Unreal Engine 5.4.4 для **Windows**(VR-гарнитуры).

## О проекте

**The Golden Ring** — это иммерсивное виртуальное путешествие по Малому Золотому кольцу России. Проект представляет собой интерактивный тур, состоящий из 5 уникальных испытаний в пяти знаковых исторических городах. Код игры единый для всех платформ.

### Зачем мы это делаем

Главная цель проекта — **образовательная**. Мы стремимся познакомить игроков с богатым культурным наследием, архитектурой и историей России в увлекательном интерактивном формате.



## Маршрут тура (Локации)

Испытания проходят в пяти городах Малого Золотого кольца:

* **Суздаль**
* **Владимир**
* **Переславль-Залесский**
* **Ростов Великий**
* **Сергиев Посад**



## Функционал (Features)

* **5 исторических испытаний** — уникальные образовательные квесты и задания в каждом из 5 городов.
* **VR-погружение** — полноценная поддержка виртуальной реальности для максимального эффекта присутствия.
* **Выбор музыки** — возможность настраивать музыкальное сопровождение по своему вкусу.
* **Гибкие настройки производительности** — оптимизация графики для стабильной работы на ПК.



## Инструкция по установке (Installation)

### Для пользователей

1. Скачайте архив с проектом по ссылке https://drive.google.com/drive/folders/10gfLNiJs7RSn7T5Ohomem06Ezvp7dEhG?usp=sharing
2. В архиве находится папка — это готовый Windows-билд для ПК ВР.
3. Запустите исполняемый файл TheGoldenRing.exe — дополнительная настройка не требуется.

### Для разработчиков (открыть проект в редакторе)

1. Распакуйте архив с проектом (структура папок Unreal Engine, `.uasset`-файлы).
2. Откройте файл `TheGoldenRing.uproject`.



> ⚠️ \\\*\\\*Обязательное требование:\\\*\\\* проект собран и тестировался именно на \\\*\\\*Unreal Engine 5.4.4\\\*\\\*. Открытие в других патч-версиях 5.4.x (5.4.0–5.4.3) не гарантируется и может привести к ошибкам.

## Примеры использования (Usage)

* **Видео геймплея:** `Video.mp4` (в папке с пользовательским билдом) — демонстрирует игровой процесс, VR-механики, локации городов.
* **Готовый билд:** папка по ссылке для пользователя содержит рабочий exe-файл для быстрого ознакомления с туром без необходимости сборки.



## Настройки (Configuration)

Все настройки доступны прямо из игрового меню:

* Качество графики (пресеты под разные устройства и VR-шлемы)
* Выбор фоновой музыки
* Чувствительность управления и настройки VR-трекинга



## Технологический стек (Tech Stack)

* **Движок:** Unreal Engine 5.4.4
* **Контент:** VillagePack, LUTs, SliderX
* **Процедурная генерация:** PCG (Procedural Content Generation)
